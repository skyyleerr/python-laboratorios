Código incorrecto del ejercicio:

class Saludo:
    def __init__(self, nombre):
        self.nombre = nombre

    def mostrar():
        print("Hola")

saludo = Saludo("Ana")
saludo.mostrar()

Causa: Python pasa automáticamente el objeto como primer argumento al invocar un método de instancia. Sin el parámetro self la llamada genera TypeError. Corrección ejecutable: saludo_corregido.py.
